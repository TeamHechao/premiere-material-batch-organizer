# 0.4.2 原件回收修复

日期：2026-10-02。

## 修复内容

旧版可能已经建立目标文件、更新 Premiere 链接并保存工程，却因时间线上的非普通媒体项被误拦，留下“目标已就绪，原文件待回收”的暂缓记录。反复检查又不会自动接续这些记录，导致看起来只完成复制，没有完成搬动。

- 完整素材箱清单记录明确的非媒体项目项；明确的调整图层不按磁盘素材检查。其他未知项、读取异常、原位置引用以及无法展开的合并或多机位素材仍阻止回收，不以忽略未知项换取完成。
- 对已知旧轨道类型误拦、曾批准转移、身份可靠且没有回收请求或历史尝试的记录，新增一次性自动接续。所属工程自动查找已开启，当前保护名单、目标身份及全部引用核验通过后，再完整比较内容、保存工程并回收原件，不重复复制。
- 核验失败保留两处文件、具体原因和尝试标记，不循环保存或无限重试。保留原件选择、暂停、保护名单、未决回收与写锁仍有效。
- 工程改名或目录移动还须 GUID 相同、旧工程文件不存在、相对目标及全部引用唯一匹配；另存为且原工程仍存在时不继承回收权限。
- 错误补充实际序列、轨道和项目项位置；面板版本号与插件清单统一为 0.4.2。
